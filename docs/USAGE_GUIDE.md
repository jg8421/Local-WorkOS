# WorkOS 使用指南

WorkOS 把同一个项目的研究材料、会议、问题、模型和交付稿放在一起。平时先选项目，再用一句话说明要做的工作；缺少必要条件时补充回答即可。需要生成材料时明确选择来源和模型，完成后检查正文、来源和计算口径。

本文贯穿使用 **Antigravity（合成示例）**。这个名称只作演示，不代表任何同名公司的业务、财务或投资判断。文中的文件、人物、日期、数值和任务均为虚构示例，与个人工作区中的真实项目无关。建议先在演示工作区试用。

## 先把项目和材料放好

1. 在研究首页新建项目，名称填“Antigravity（合成示例）”。只填名称也可以开始，行业、阶段等以后补充。
2. 导入合成的公司介绍、Memo、协议、访谈笔记和模型文件。可以批量选文件或文件夹。项目内会自动整理子任务和版本组，仍保留每份记录。
3. 检查自动分类。例如 `合成Memo_v1.docx`、`合成Memo_v2.docx` 会作为同类材料的不同版本；协议、访谈笔记可以分别查看。最近导入的版本不自动认定为获批终稿。

项目用来串起同一个对象的工作。研究和会议仍是主要入口，不需要再把同一家公司的材料分散到多个重复项目。

在运行 WorkOS 的本机，可以配置项目根文件夹。系统只自动采用唯一且可靠的名称匹配；多个候选会请你选择，没有匹配则先使用本机托管文件夹。每次保存产物都能查看实际目录、文件和状态。演示产物只进入演示托管目录，不写业务文件夹。

## 用一句话开始，不必先理解所有工作类型

可以在首页输入：

> 帮我看一下 Antigravity 的材料，先给我三个最值得追问的问题，每个问题说明为什么问、该问谁。

软件会识别工作目的。若“看一下”不足以确定你要摘要、尽调还是投资讨论，会先问一个关键问题；若还没选材料，会提示选择。回答后继续同一任务，已确认的要求、项目和模型会保留。

明确目的能更快开始，例如：

> 根据我选中的公司介绍和两份合成访谈笔记，做一页讨论材料。只谈商业模式和需求证据，保留专家之间的分歧。

所选资料是本次工作的范围。要加入另一份材料或切换项目，请明确调整选择并开启对应的新对话；旧草稿里的引用不能替代本轮来源。材料里要求模型执行命令的文字只作为文件内容。

研究工作台的一个输入区支持三种用途：问资料、生成工作材料、操作工作区。短问答适合先理解材料；需要保存成 Word/PPT 的完整正文时选生成材料；“保存这条结论”“建一个待办”“整理项目材料”使用工作区操作。

## 选择和添加模型

首页、研究、行动、纪要和估值使用同一个按供应商分组的模型选择框。可以按当前目录选择 GPT/DSH、DeepSeek、GLM、Kimi、Hunyuan、桥接别名或已配置兼容接口。目录显示可用性检测状态；未检测不表示保证可用，检测失败也不会自动改用另一模型。

添加一个兼容服务时，在设置填写供应商名称、显示名称、服务地址、准确的模型 ID 和需要的 API 密钥，保存后检测模型连接，再在工作入口选择该配置。可以保留多个连接；名称、地址和模型编号会保存，密钥仅留在当前进程内存，重启后需要重新填写。外部地址使用 HTTPS，本机兼容桥接可以使用 HTTP。检测只发送合成 JSON，不读取项目材料。已有 DSH 登录通过本机 DSH 使用，无须把 OAuth 凭证复制进 WorkOS。

模型名字相同不保证能力相同；桥接服务返回的模型 ID 也不能独立证明上游身份。工作开始后保留明确选定的模型，失败时可以重试或自行选择另一模型。

## Antigravity 项目的一条完整工作链

不必把下面所有步骤一次执行完。每次围绕当前需要选择用途，完成一份可以核验的产物。

### 先理解公司和技术

**研究概要、技术解释、尽调**适合从初看材料走向深入问题：

> 先按选定材料写300字公司概要，最后只列两个资料缺口。

> 用通俗中文解释合成公司材料里的技术路线，比较优势、代价和适用场景。需要一张对照表，准备导出可编辑HTML。

> 整理当前尽调发现，结论先行，区分管理层说法、专家观点和团队假设。标明材料版本、缺口和下一轮最重要的问题。

技术概念解释可以先没有资料，但会作为未核验的概念草稿。公司判断和尽调需要明确选来源。生成时会显示每份材料实际提供的文字范围；部分摘录不能当作已经读完所有材料或完成全部尽调。

### 准备访谈，再整理会议

**访谈提纲、专家需求邮件、表格纪要**可以前后衔接：

> 根据已选研究材料，准备五个访谈问题。按优先级排序，说明每个问题验证什么、适合问什么背景的人。

> 帮我拟一封英文专家需求邮件：先写目标对象，再写优先背景和筛选条件，最后列核心问题；请对方反馈候选人的匹配情况。

> 把两份合成访谈笔记整理成“议题×专家”对照表。保留观点归属和矛盾，最多六列，最后列待验证事项。

有逐字稿时，在会议页粘贴或上传转写，选择模型生成结构化纪要。音频本身不会自动录音或转写；没有可读转写时先补材料。生成后可手动修正专家背景、数字和措辞，再说：

> 在当前已保存纪要上，把访谈内容压缩一半，保留数字和分歧，把行动项写清楚。

软件读取当前保存的修改和同一会议的历史，不把你的手工修订换回旧版。保存后生成新的归档版本，可下载 Word；PDF 依赖本机配置的转换组件，无法转换时仍可使用 Word。

### 做交易文件和投资讨论

**协议审阅、版本对照、邮件、讨论材料、IC Memo**围绕当前问题使用：

> 审阅选中的合成协议，按条款列商业影响、待确认问题和谈判建议，不能从材料外补造法律事实。

> 对照合成Memo的两个版本，列实质变化、数据冲突和待确认项。不要把两个版本当作两份独立证据。

> 帮我拟一封简短英文邮件，请对方确认clean version和签署状态。只有明确给出的日期和附件才写进正文。

> 写三页讨论材料：为什么现在讨论、现有证据支持什么、需要作什么决定。详细支持放附录。

> 基于已选材料写IC Memo草稿，明确实际与预测、管理层口径与团队判断，列出缺口和待决问题。

邮件是可编辑草稿，不会发送；不会声称附件已发送、会议已排定或交易已承诺。协议审阅输出待确认问题和建议。讨论/IC 材料可导出 Word、PPT 和 HTML，页数与排版仍需检查；普通PPT导出不等于已完成机构专属母版的整套演示稿。

### 用已有成果更新项目

**项目更新、Excel模型审阅**适合接续前面的工作：

> 根据选定材料和项目已有会议、结论、任务，写本次项目更新：新增发现、仍未解决的问题、下一步。不要把记录保存日期当作业务变化日期。

> 审阅选中的合成Excel模型，检查驱动、币种、期间、公式证据和来源映射，明确哪些内容没有提取到。

Excel审阅使用导入时提取的内容。它不会运行宏、直接修改原工作簿，也不会把缓存值当作已经重新计算的结果。

以上覆盖十三种工作材料：研究概要、尽调、IC Memo、讨论材料、技术解释、协议审阅、访谈提纲、专家需求邮件、邮件、项目更新、版本对照、Excel模型审阅、表格纪要。结构化会议和估值另有专门页面。

## 用口语补齐估值条件

目前有四种结构化方法：净利润×P/E、股权P/S、FCFF DCF、单层债务LBO。模型负责整理你给出的假设，Python 执行测算。软件不会根据缺少的数字自行补默认假设来给出“准确回报”。

可以先输入不完整要求：

> 看一下 Antigravity 的回报，退出倍数按12倍，先算MOIC和IRR。

软件会继续确认进入投入、回收口径、持有日期及适用方法等必要条件。这里“12倍”缺少利润/收入/EBITDA口径，不能直接当作足够的测算数据。币种、金额单位、实际或预测期间也需要明确。

一个完整的简单估值输入可以是：

> 仅作合成演示：币种人民币，金额单位百万元；FY2025实际净利润100，P/E 12倍。先算股权价值，不计算IRR。

整理出的条件可以继续口语修改：“把P/E改成10倍，其余条件沿用。”检查条件表后计算，结果可保存成项目模型记录、重开修订、比较情景，并下载带公式的 Excel。清楚的数字字符串、百分比和倍数可以整理；含糊的金额口径仍需确认。高级结构化字段用于检查和精确修改，不必作为第一步学习内容。

MOIC 表示退出回收与进入投入的比值；没有期间分红时，IRR 还取决于持有时长。当前结构化LBO考虑单层债务、年度现金流和同权卖方滚存，以实际进入/退出日期计算回报；每个预测行对应完整年度。期间分红、多层债务、优先分配、ESOP/IPO稀释、任意零碎期间和完整三表模型尚未实现。若需要这些功能，可以先生成假设清单或审阅外部模型，不能把现有测算当作已经覆盖。

页面另有历史简化权益回报测算，使用其明示的固定口径和简化现金转换；它不是完整LBO，也不直接接受任意交易结构。

## 修订、停止、保存和交付

- 对话可继续提问和修订。Enter发送，Shift+Enter换行；正文编辑器、逐字稿和高级JSON编辑区仍用于正常编辑。
- 生成中可以停止。尚未保存的后续操作不再提交；已经完成的操作会显示结果，不倒回删除。再次开始使用新请求，旧回复不会覆盖新草稿。
- 交付稿修订读取当前已保存正文，生成新版本，原稿仍保留。需要把手工编辑纳入修订时，先保存编辑再提交要求。
- 快速草稿适合小任务；深入整理会增加要求检查、复核和必要的一轮修订。执行记录显示可核验步骤和实际资料读取范围，不展示模型私有推理，也不保证事实已经独立验证。
- 工作材料、纪要、研究笔记和保存的模型可以自动归档。普通“问资料”不会每次自动写项目文件，想保留时明确保存。
- 归档或格式转换失败时，可单独重试导出，不必重新生成正文。文件按版本保存，原材料不会被覆盖；下载前可核对目录和文件状态。
- HTML可以独立打开、修改正文、批注并另存副本。独立副本的修改不会自动回写 WorkOS 数据库。

缺材料或条件时继续回答问题；源文件已变、项目/材料范围不一致时重新确认范围；模型服务故障时查看所选模型检测状态后重试。个人记忆只做本地检索，不进入模型研究对话；个人与演示工作区使用独立记录和目录。
